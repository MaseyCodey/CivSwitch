MacroCiv7 chat-XSS payload

This is the payload this project currently uses for Civilization VII (87 lines typed into the in-game chat). JP-only consoles need Alt+Space (IME toggle) before every line; international consoles do not.
The macro only runs when the console has enumerated the device (USB = ready).
Hold the BOOT button for 2 seconds to run the macro in international mode without touching this page.
